# 塔罗牌的历史

1442年，意大利费拉拉市的一部文献中首次出现了“塔罗”一词。

1450年至1460年间，现存至今最古老的几副塔罗牌在意大利的米兰和费拉拉市被创作出来，包括《维斯康蒂塔罗牌》和《曼特纳塔罗牌》。

在法国作家弗朗索瓦•拉伯雷1534年的名著《巨人传》中，塔罗牌是书中主角最喜欢的纸牌游戏之一。这是塔罗牌存在于法国的最早证据。

1660年，诺布莱与维埃耶在巴黎印刷了一副用于娱乐的《马赛塔罗牌》，此后，法国、意大利、比利时、瑞士和德国都开始印刷这种牌，它风靡了整个欧洲。

法国神话学者安东尼古•德•杰柏林在1781年至1783年间宣称塔罗是源于埃及对透特神的崇拜，这大大地迎合了当时欧洲人极度痴迷埃及文化的潮流。

基于杰柏林的这种虚构说法，巴黎的神秘学家艾特拉在1788年设计了一副埃及图案风格的塔罗牌，这是市面上第一副用于解读的塔罗牌。

1855年至1856年间，埃利法斯•例维发表了《高等魔法教义与仪式》。他对塔罗牌与希伯来秘法进行了关联研究，并把塔罗牌放在了神秘学的中心。

1870年，让巴蒂斯特皮图瓦以保罗克里斯蒂安为笔名发表了著作《魔法学史》，他不仅完善了艾特拉的塔罗牌解读系统，也继承了塔罗起源于埃及的这个虚构理论，他指出塔罗就是阿卡纳，代表着“秘密”。

1888年，威廉•韦恩•维斯科特、麦克格雷格•马瑟斯和威廉•K•伍德曼在伦敦成立了金色黎明赫耳墨斯教团，这个教团研究整合了大量神秘学和魔法系统，并形成了完整的神秘学体系。

1909年，金色黎明教团成员亚瑟•爱德华•维特和潘蜜拉•柯曼•史密斯共同创作了举世闻名的《莱德维特史密斯塔罗牌》。这副牌汲取了大量金色黎明的研究成果，它给后世的塔罗牌带来了不可估量的持续影响。

1927年，精通象征主义的奥斯瓦德•怀斯出版了《中世纪图像师塔罗》，这本书是法国神秘学的概要性著作，随书还附赠了22张由他自创的塔罗牌。

1944年，阿莱斯特•克劳利出版了《透特之书》，这部作品里还包括了在克劳利的指导下由弗里达•哈里斯所创作的《透特塔罗牌》。
